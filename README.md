# Dynamic Resume Builder App

A clean and accessible web application designed to help users build modern resumes with ease.

## ✨ Features
- **Input Forms**: Easy step-by-step entry for contact info, skills, education, and experience.
- **Instant Preview**: Visual resume card updates dynamically.
- **Download / Print Ready**: Formatted for standard A4 printing and PDF export.

## 🛠️ Tech Stack
- **Frontend**: JavaScript, HTML5, CSS3
